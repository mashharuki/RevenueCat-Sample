## 参加要件（失格を避けるための必須事項）

1. **新規アプリであること**: iOS / iPadOS / macOS / Android 向け。初回公開が提出期間内（8/1〜9/30）であること。**既存アプリのアップデートは対象外**
2. **RevenueCat SDK の統合**: 少なくとも1つのアプリ内課金（in-app purchase / web purchase）を RevenueCat 経由で実装、または RevenueCat Ads で広告配信すること
3. **ストア公開**: App Store / Google Play / Samsung Galaxy Store のいずれかに公開済みであること
4. 参加者は居住国の成年年齢以上であること（一部の国・地域は除外）

## 賞カテゴリ: RevenueCat主催9つ＋スポンサー賞7つ＋インフルエンサー賞5つ＝合計21カテゴリ

以下はRevenueCat主催の9カテゴリ。**スポンサー賞（JetBrains/Noise/Replit/OneSignal/Layers/Stripe/Samsung）とインフルエンサー賞（Productivity/Nutrition/Yoga & Fitness/Career Coaching/Gaming の5部門）は `references/sponsor-and-influencer-awards.md` に詳細をまとめてある。** 特にインフルエンサー賞は審査員個人が公言している「欲しいアプリ像」がそのまま基準になっており的を絞りやすいため、ユーザーの経験がこれらのニッチに近い場合は必ず案内すること。

### 1. Grand Prize（1位 $100,000 / 2位 $20,000 / 3位 $10,000）
- **審査基準**: プロダクトの完成度に加え、審査期間中にどれだけユーザーの反応・成長の勢いを作れたか。具体的には (1) リリース後のユーザー獲得 (2) SNS/コミュニティでの話題性 (3) ユーザー反応を受けた改善 (4) 課金・収益化の導線 (5) 成長のストーリーをDevpostで伝えられているか、の5点。「作って終わり」ではなく「作って、出して、伸ばす」ところまでが審査対象
- **狙い方**: プロダクトの質だけでは獲れない。8月上旬に早期リリースして9月をまるごとグロース期間に充てる。市場の広い課題×低CACのバイラル要素が必要。難易度は最高

## 一般的な審査観点（全カテゴリ共通の土台）

- **Innovation**: 市場に対する新規性（新しいアイディア・機能・ユースケース）
- **Execution**: 実装の完成度・安定性・視覚的一貫性
- **Feasibility**: ハッカソン後も現実的に成長・継続できるか
- **Integration**: RevenueCat SDK / API の効果的な活用

## カテゴリ選定の指針

1. **主軸1つ＋副次1〜2つ**を選ぶ。全方位狙いは全敗する
2. 主軸はユーザーの強み（デザイン力・マネタイズ思想・当事者性・発信力）と一致させる
3. #BuildInPublic は常に副次として乗せる
4. グランドプライズは「結果として獲れたら嬉しい」位置付けにし、設計段階ではカテゴリ賞に最適化する方が期待値が高い（競合812作品→608提出の中で戦うため）
5. スポンサー賞・インフルエンサー賞（`references/sponsor-and-influencer-awards.md`）は、RevenueCat主催の9カテゴリより認知度が低く応募数が少ない可能性が高いため、コンセプトが合致するなら積極的に主軸/副次として組み込む。特にインフルエンサー賞5部門は審査基準が個人の具体的な要望ベースなので、対応するニッチ（生産性・栄養/食事・ヨガ/フィットネス・キャリアコーチング・ゲーム）に強い経験や熱量があるユーザーには最優先で案内する

## 日本からの参加動向と戦略的示唆（2026年7月時点）

出典: ユーザー共有のX投稿（開始1ヶ月前の事前登録データ、一次ソース未確認のため参考情報として扱う。数字の断定はせず、時流の把握に使うこと）

- 日本からの登録数がグローバル全体の**半数以上**を占めている（事前登録の時点で計測）
- 2025年は開催期間を通じて日本からの参加者は約240名。2026年はすでにその**約5倍**に達している（しかも開始1ヶ月前の時点）

**この統計が示す戦略的含意**:
- 日本語圏コミュニティでの参加規模が前回比で大きく拡大しているため、**定番テーマ（習慣化アプリ・家計簿・日記・単純なポモドーロ等）は同時多発的にかぶりやすい**。Phase 2 のアイディア出しでは「本人が語れる本物の課題」の掘り起こしと差別化ポイントの明確化を、例年以上に重視すること
- 一方でグローバル審査という土俵では、日本語ローカライズやニッチな日本文化文脈に根ざしたテーマは差別化要因にもなり得る（審査員に伝わるよう英語のピッチ・デモ動画での説明を丁寧に作ることとセットで）
- #BuildInPublic は日本語コミュニティでの発信だけでなく、英語圏（X等）での発信も並行するとグランプリ/#BuildInPublic Award 双方への相乗効果が期待できる

## 複数アプリ提出・複数受賞の扱い（要確認事項）

昨年（2025年）は1人が複数アプリを提出することが可能だった。2026年に同じルールが継続されるかは本稿執筆時点で不明。複数アプリ提出の可否や、1人・1チームが複数賞を受賞できるかの扱いは、**公式ルール（Official Rules）確定後に必ず確認する**よう、ユーザーが「並行して複数アイディアを進めたい」と言った際には案内すること。
